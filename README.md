# ICS Hack 'n Track

Thank you for registering for ICS Hack 'n Track.

Please read and complete the following before workshop day:

1) Bring your private laptop with an SSH client installed and tested.
2) Make sure you can access the GitHub page once it is shared.
3) Review the short primer on ATT&CK for ICS and industrial protocol communication fundamentals (link shared in the GitHub repo).

During the workshop, you will work inside your own isolated AWS VPC. No local virtualization, PLC hardware, or paid software is required. Prior experience with Caldera, Malcolm, Siemens S7, or industrial environments is helpful but not required.

Workshop Communication and Support:
- Updates and workshop changes will be posted on GitHub: https://github.com/hydrosam/DEFCON34-ICS-Workshop
- Questions or other support: pedro.cabrera@siemens-energy.com, hannes.heck.ext@siemens-energy.com, jordan.sanchez@siemens-energy.com, sam.miorelli@siemens-energy.com

If you cannot complete setup before the event, still attend. We will provide fallback options so you can participate.

See you at DEF CON.
